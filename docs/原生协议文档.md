# 极核 ZEEHO 原生桥 · 协议文档（142 接口）

来源：`zeehowebnext 1.8.70` 反编译源码 `ShellBridge.java`（142 个 `@JavascriptInterface`）+ `ZeehoCastBridge.java`（10 个）。
调用约定：全部同步调用，`window.ZeehoShell[method](...args)`，参数按 JS 展开顺序传入，返回值一律为字符串（多数是 JSON 文本）。

命名规律：长任务统一是 `beginXxx → pollXxx → xxxAction → cancelXxx` 四段式；`poll` 返回进度与阶段，`action` 做二次确认，`cancel` 终止。

> H5 面板实际只调用了其中 58 个，剩下 84 个是壳有、页面没用到的能力，表里全部列出。

## 备注

- 参数类型是 Java 侧声明，JS 调用时可传 `undefined`/`null`，原生实现里普遍做了空值兜底。
- 返回 JSON 里常见字段：`ok`、`error`、`message`、`status`、`stage`、`progress`、`handle`、`version`、`key`、`identity`。
- 长任务的 `handle` 由 `begin` 返回，后续 `poll/action/cancel` 必须带同一个 handle。
